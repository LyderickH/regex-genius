# Regex Genius

Outil web permettant de déduire automatiquement des expressions régulières (Regex) à partir d'exemples de données textuelles (à la manière de la fonctionnalité « Colonne à partir d'exemples » de Power Query / Excel).

## Stack technique

- **Framework**: TanStack Start / React 19 / Vite
- **Styling**: Tailwind CSS v4, shadcn/ui (Radix UI)
- **Routing & State**: TanStack Router, TanStack Query
- **Parsing**: PapaParse (CSV), XLSX (Excel)
