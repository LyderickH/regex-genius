# Regex Genius

Outil créateur de regex a partir d'exemple

En gros comme dans powerquery quand tu fais créer une colonne à partir d'exemple

Colonne 1 tu met tes données (faut pouvoir copier coller ou importer txt csv excel)
Colonne 2 tu met le resultat attendu sur chaque ligne et eventuellement la possibilité de splitter le résultat en plusieurs colonnes colonne 3 4 5 6 ect
